This dictionary builds on "Den stora svenska ordlistan" / SFOL, originally
maintained by Göran Andersson <goran@init.se>
(https://extensions.libreoffice.org/extensions/swedish-spelling-dictionary-den-stora-svenska-ordlistan),
extended with data from SALDO/SALDOM (Språkbanken Text, CC BY 4.0),
Folkets Lexikon (KTH), Datatermgruppen's IT terminology, SAOL 15, and
translation-memory entries from Swedish open-source software localization.
See https://github.com/yeager/hunspell-sv for the full source breakdown.
